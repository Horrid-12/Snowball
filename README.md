# ❄️ Snowball

Snowball is a personal productivity hub built for staying consistent without juggling a bunch of separate apps.

It combines the parts of a daily system that usually get scattered around:

- task management
- habit tracking
- deep work / focus timing
- a consistency heatmap
- scratchpad notes
- media tools for study or work sessions like Youtube and Spoyify (Spotify is just for experimentation purposes and I cannot Provide Access to spotify) 

The idea is simple: open one app and run your whole routine from there.

## 🚀 What Snowball Does

Snowball helps you:

- create and track tasks with priorities, dates, time blocks, and progress
- build daily habits and mark them off quickly
- run focused work sessions with a built-in timer
- see your momentum over time through the activity heatmap
- keep quick notes and reminders in a scratchpad
- use desktop, Android, and web versions of the same app

## 💻 Platforms

Snowball is available as:

- a desktop app
- an Android app
- a website

## 🛠️ Main Features

- Task board for planning and execution
- Daily habits tracker
- Deep work timer
- Activity heatmap
- Scratchpad notes
- Media hub for Spotify and YouTube workflows
- Dynamic theming and cross-platform UI
- Offline-first local behavior with sync support

## 📦 Stack Snapshot

- Vercel for web hosting
- Tauri for desktop
- Capacitor / Android Studio for Android
